
# NxtPanel - iOS

**A Powerful Admin Panel for NewsNxt Support Management**

NxtPanel is an iOS application designed to help administrators of NewsNxt manage user queries efficiently. With real-time chat functionality, admins can address user concerns, resolve issues, and provide seamless support directly from their iPhones or iPads.
## Version History

**v1.0 (Current Version)**

- **Admin Authentication:** Secure login system for NewsNxt administrators.
- **Query Management:** View, track, and resolve user-generated support tickets.
- **Real-time Chat:** Engage in real-time conversations with users to address their concerns.
- **User Query Dashboard:** Overview of all open, pending, and resolved queries.
- **Chat History & Logs:** Maintain a history of conversations for future reference.

## Features

- **Secure Login:** Ensures that only authorized NewsNxt administrators can access the app.
- **Real-time Query Handling:** Admins can chat with users in real-time to solve their problems efficiently.
- **Ticket-Based System:** Each user issue is categorized as a ticket for structured management.
- **Conversation Logs:** Stores chat history for future reference and accountability.
